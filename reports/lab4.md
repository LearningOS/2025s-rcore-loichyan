## 问答题

### Easy-fs 中 root inode 的作用

根节点，即 `SuperBlock`，记录了文件系统中各连续区域的位置[^1]，包括索引区域和数据区域，是文件系统能正确加载的基石．如果根节点被篡改，也就意味着文件系统了解到的数据分布与存储介质上实际的数据分布不一致，从而导致部分数据损坏．如果根节点彻底损坏无法读取，这意味着文件系统便无法得知存储介质上的数据分布，从而导致整个文件系统损坏．

### Pipe 的应用

使用 ripgrep 配合 perl 对项目下所有文件进行正则替换：

```sh
rg '<search>' --files-with-matches | xargs perl -pe 's/<search>/<replace>/g' -i
```

使用 ripgrep 配合 xargs 保留某个章节的测试程序：

```sh
ls user/src/bin | rg -v '^ch6_' | xargs rm
```

### 设计多进程通信机制

维护一种特殊的文件：

1. 此文件允许多个读者，并且它们共享文件的游标（cursor）；
2. 此文件允许多个写者，它们也共享光标，但不同于读者；
3. 内核保证此文件按照 FIFO（First In First Out，先进先出）读写；

这样，实际上此文件相当于一个多进程共享的队列，可以用来实现 MPMC（Multiple Producers to Multiple Consumers，多生产者多消费者）通信模型．
